其他常见工具

“常用量表”没有一张穷尽所有医院的固定清单。以下提供用途和获取方向，未将受授权限制或需要专业解释的工具直接复制成自动诊断。

工具用途及本网站处理
HADS 医院焦虑抑郁量表自评，焦虑和抑郁各 7 项，两个分量表分别计分；由 GL Assessment 提供。需核对数字化与中文版本授权，本站提供获取链接。
BDI-II / BAI贝克抑郁／焦虑自评工具；Pearson 管理的受版权保护测验，本站不公开复制题库。
DASS-21 / DASS-42抑郁、焦虑、压力量表。DASS-21 各分量表相加后乘 2（不是 21 项求一个总分）。开发者明确不建议向受测者自动提供分数解释，本站提供官方资料。
CES-D流调与初级医疗中用于抑郁症状筛查的自评工具。20 项版本与缩短版计分不同，本站提供 APA 获取入口，未混用其阈值。
GDS老年抑郁自评量表，存在 30 项与 15 项等版本；应考虑年龄与认知情况。官方获取入口见 APA。
QIDS-SR16抑郁症状自评；16 项归入 9 个症状域，不能将 16 项简单相加。需按正式版本与手册实施。
SCL-90 / SCL-90-R广泛心理症状自评，包含焦虑与抑郁维度；不同版本与常模不能混用。不能用总分诊断某一种疾病。
HAMD / HAMA / MADRS医院也常用，但通常由受训人员访谈评定，属于他评工具，不作为患者自行填写的问卷上线。

    PRIVACY BY DESIGN

    你的回答，留在本机。

    答案和分数不上传

    计分直接在浏览器里完成。本站没有数据库、登录、统计追踪、广告、远程字体或第三方脚本；不把答案、分数或历史记录发送给 GitHub 或其他服务器，也不将这些数据放进网址。

    默认只在本次页面中使用

    答题过程保存在页面内存中，刷新或关闭会丢失。完成后，只有你点击“保存到本机”才会写入此浏览器的 localStorage。切换设备或浏览器不会同步。清理浏览器数据会删除记录。

    本机记录不等于加密保险箱

    记录没有加密，同一设备和浏览器的其他使用者可能看到。浏览器扩展、操作系统备份以及同域其他页面的行为不在本站控制之内。共用设备建议不保存，使用后关闭页面。

    访问网页仍需要网络

    GitHub Pages 提供网页文件，托管方可能处理 IP 地址、访问时间等常规访问日志；这些与量表答案、分数不同。点击参考链接会访问相应外部网站。本站不承诺整个设备完全没有网络活动。

    导出由你决定

    导出的报告和记录直接下载到设备；如果主动分享、同步下载目录或发送给医生，文件会按你的操作离开本机。没有自动发送或临床人员后台查看功能。

    离线版用浏览器打开即可计分；某些手机文件预览器不执行脚本，请用支持本地 HTML 的浏览器。没有安装服务工作线程，不会缓存或控制同域其他网站。
